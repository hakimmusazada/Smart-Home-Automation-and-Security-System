# Hardware Components

This document lists the main electronic components used in the Smart Home Automation and Security System.

| Component | Function |
|---|---|
| Arduino UNO | Main microcontroller responsible for controlling the system |
| DHT11 Sensor | Measures temperature and humidity |
| HC-SR04 Ultrasonic Sensor | Detects nearby objects and measures distance |
| SG90 Servo Motor | Controls the locking mechanism |
| IR Receiver | Receives commands from the remote control |
| MAX7219 LED Matrix (4 × 8×8) | Displays system status, notifications, and the Dino mini-game |
| Buzzer | Provides audible alerts |
| LEDs | Indicate system status and security alerts |
| Push Button | Allows physical mode control |
| Raspberry Pi 4B | Used as part of the system's computing and control setup |
